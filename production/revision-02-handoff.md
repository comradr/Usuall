# Изменения 0.2

Выполнены актуальные правки пользователя: полный viewport, горизонтальный сплит 50/50 на всех размерах, пауза при портретной ориентации, запрос Fullscreen API по пользовательскому жесту, телефон с сообщениями в нижнем правом углу и команды физических действий. Удалены прежние оформление статьи, внешняя переписка, PIP и перемотка действия.

Текущий фрагмент содержит две исходные сцены, 189 секунд сюжетного времени и пять неизменённых сообщений. Команды: 10 фасовать, 35 написать пример, 56 обслужить, 79 перенести, 102 выставить, 145 ответить. Покупатель появляется на 20, приходит на 34 во время фасовки, ждёт обслуживания; отдельный пакет переходит касса→Вова→покупатель, хлеб сохраняется в количестве шести. Телефон Вовы достаётся после команды145–147, сообщения появляются в прежнее время152/159.

Сохранение v2 записывает последовательный журнал команд до события принятия. Продолжение сохраняет середину действия; старое автоматическое сохранение переносится к началу незавершённого интерактивного сегмента. Невалидный журнал отвергается. Diagnostic renderAt остаётся каноническим replay и не используется игровыми кнопками.

Новые NPC созданы через встроенный imagegen: исходник1897×829 RGBA, три строки по восемь поз — мальчик, девочка, взрослый покупатель. Задание: анонимные персонажи в существующей тёплой пиксельной манере, обычная одежда, полные связанные силуэты, позы ходьбы/сидения/письма/поднятой руки и получения покупки. Личные фото не использовались. Источник: production/art-source/npcs-source-v1.png; нарезка: src/build-assets-npcs.py; атласы: dist/assets/npcs/*.png; просмотр24поз: production/npc-review-sheet.png. Экспорт только нарезает и нормализует исходные пиксели, без дорисовки конечностей.

Один ограниченный цикл исправил закрытые партами лица и разрыв передачи пакета: offset сидящих поз−12px кроме задней правой парты; pickup использует соседние позы5/6, выход использует четыре обычных шага и маршрут к переднему краю без зеркального скачка руки. Художественная приёмка полноценного шага и старые дефекты Насти остаются в независимом обзоре.

Проверено46технических случаев, актуальный build и native доказательства подписаны отдельно. Node/native Canvas и Node VM не являются браузером. Проверка настоящего телефона, CSS layout, аудио и FPS пока отсутствует. Исторические отчёты0.1 сохранены отдельно и не выдаются за новую проверку.
