# Обычный день · интерактивный фрагмент0.3.0

Магазин Вовы и класс Насти идут рядом в равном горизонтальном сплите. Реализованы S02 «Хлеб и доска» и S03 «Хлеб выставляю»,189 секунд сюжетного времени без ожидания команд. Девять остальных сцен полного дня остаются в разработке.

## Текущие изменения

- Подключены11новых полнофигурных кадров Насти: обычная ходьба, подъём и опускание руки с мелом. Все28предыдущих клеток и спрайты учеников/покупателя сохранены.
- Подъём35–35,9с; письмо35,9–46,2с; опускание46,2–48с. Мел один: удерживается в руке до карманного контакта130,65с, затем телефон появляется130,85с.
- Модель работает без графических данных, состояние penDown сбрасывается после письма. Сохранение смены владельца мела выполняется перед кадром и обновлением интерфейса.
- В предыдущем checkpoint3f261e2 уже сохранены точные области нажатий для шести действий, сохранения покупок до отрисовки, компактный/раскрытый телефон и сообщения об отказе fullscreen. Эти изменения присутствуют в текущем коде.
- Пять исходных сообщений и время136/152/159/170/176с сохранены. Сохранения версии2 совместимы.

## Исходники и проверка

Статическая игра находится в dist/. ES-модулям и JSON нужен HTTP; file:// не поддерживается. Исходники: https://github.com/comradr/Usuall. Приватная игра: https://obychnyy-den-vova-nastya.pinkexpr.chatgpt.site.

node src/build-engine.mjs пересобирает движок. python3 src/build-assets-nastya-v4.py экспортирует позы из оригинала production/art-source/nastya-motion-source-v4.png; python3 src/integrate-nastya-v4.py добавляет их к полному baseline production/art-contract-interactive-v3.json с NPC. Неверный raw6 исключён, полный источник и лист проверки всех12поз сохранены.

npm run check проверяет синтаксис; npm test — модель/native Canvas/интерактив/UI-логику. Новая независимая проверка текущего восстановления сохраняется в production/recovery-qa-critic/. Исторические qa/critic отчёты0.1/0.2 и результат70/70утраченной предыдущей рабочей копии не подтверждают эту пересобранную версию.

node scripts/build-native-preview.mjs создаёт актуальные poster/GIF через реальный renderer. В каждом окне монтаж1×; это не запись браузерного интерфейса. Хеши источников и кадров: production/native-preview-recovery.json. Точный build ID: production/build-manifest.json.

Художественная приёмка остаётся BLOCKED: старые шаги Насти24–27 с поднятым мелом требуют правильного чередования опорной ноги. Новые контактные шаги имеют неоднозначную опорную ногу. Реальные mobile DOM/touch/fullscreen, звук, FPS и browser localStorage остаются NOT_CHECKED. Это приватный прототип двух сцен, не завершённый11-сценный день.

Автоматическая очистка среды удалила промежуточные файлы до коммита.
