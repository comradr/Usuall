# Обычный день · первый игровой фрагмент 0.1.0

Черновик по авторской концепции v3.0. Реализованы S02 «Хлеб и доска» и S03 «Хлеб выставляю»: 189 секунд исходной монтажной шкалы, магазин и второй класс. Остальные девять сцен полного дня ещё не реализованы. Этот фрагмент предназначен для просмотра; готовность релиза и творческое одобрение не заявляются.

## Запуск

Статическая браузерная версия: `dist/index.html`, сопутствующие JS/CSS и `dist/assets`. Для локального запуска нужен HTTP-сервер статических файлов; модули/JSON не рассчитаны на открытие index.html через file://. Site связан с проектом через `.openai/hosting.json`; его аудитория остаётся приватной.

Фрагмент проходит автоматически. Есть пауза, темп 1×/2×, ускорение текущего действия, повтор и продолжение сохранения. В портретном режиме можно вручную менять основную камеру. Сообщения сохраняют исходные слова, регистр и порядок.

## Проверки

`npm run check` и `npm test` прошли: 33 технические проверки без ошибок. Испытания выполняет Producer в Node с native Canvas и подставленными часами/хранилищем; отдельный независимый критик оценивает качество. Его окончательный вердикт — **BLOCKED**: два открытых P1 и непроверенные браузерные аспекты. Обзор и обязательный gate находятся в `production/critic-review.md` и `production/quality-gate.json`; фактический результат структурной проверки — в `production/quality-gate-validation.json`.

`node tests/capture-offscreen.mjs` экспортирует кадры напрямую из общего игрового рендера, все позы, границы действий и отдельные клипы в обычном темпе. `node tests/qa-report.mjs` проверяет соответствие хешей тестов и кадров текущим исходникам. Это не browser screenshots. Browser/mobile DOM/touch, прослушивание звука и фактический mobile FPS остаются NOT_CHECKED: обязательный control-browser недоступен в управляемом окружении, обходной браузер не запускается.

Ходьба Насти пока имеет неоднозначное чередование ног. Две попытки исправления не дали подтверждённого результата; это открытый дефект анимации. Кроме того, поднятие руки перед первым штрихом и её опускание после примера происходят резким переходом. В существующем атласе нет подходящих промежуточных поз; перестановка других кадров лишь переносит скачок. Новые позы телефона и поднятой руки не означают, что эти дефекты решены.

Сборка сохраняется как черновик для просмотра. Правило `pixel-game-studio-orchestrator` требует после двух неудачных циклов передать проблему с доказательствами и не продолжать бесконечный цикл ремонта; при открытых P1 запрещено заявлять успешную приёмку. Следующий производственный шаг — подходящие позы ходьбы и полного действия с мелом, затем проверка в поддерживаемом браузерном окружении.

## Пересборка

`node src/build-engine.mjs` копирует проверенные исходники двигателя в `dist`. `python src/build-assets.py` пересобирает графику из сохранённых источников и запускает phone/v3 finalizers: итоговый атлас Насти содержит 28 поз. Пересборка не обращается к генератору изображений. После изменения исходников необходим новый прогон проверок и обновлённый независимый обзор.

Проверочная среда: Node 24.19.0, установленный `@napi-rs/canvas` 0.1.100 и Python/Pillow. В браузерную сборку эти зависимости не входят. Промежуточные PNG для кодирования GIF воспроизводимы; обязательные raw/state и обзорные материалы сохраняются отдельно от них.
